# Роман Карпов — учебный сайт

Запуск проверок

```sh
npm ci
npm run lint
npm test
npm run build
```

Для просмотра откройте index.html. Публикуются файлы из dist.
В Settings → Pages выберите GitHub Actions.

CI проверяет изменения и собирает сайт. CD публикует результат.
При ошибке тестов ci завершается неуспешно, deploy пропускается.
needs: ci задаёт зависимость от успешной проверки.
Артефакт — собранные файлы сайта, передаваемые на публикацию.
Для pull_request условие deploy ложно, поэтому выполняется только CI.

Для эксперимента линтера временно добавьте незакрытый div.
Для эксперимента теста временно замените npm test на exit 1.
После демонстрации восстановите рабочую версию.

Проверка Pull Request выполняет только CI.
